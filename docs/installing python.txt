Installing Python
Running from the command line
These require skill in using computer terminal apps.
## Install on Windows
Go to the Python download page: python.org/downloads
Select the latest Python 3 version
run the installer and select Add Python to PATH (e.g., Python 3.14)
Alternatively install from the Microsoft Store (latest version)
Test the install
open command prompt and run to test:
C:> python --version
Python 3.14
to run, launch the Python Shell run IDLE from the Start menu

## Install on MacOS
open Applications > Utilities > Terminal
run:
brew install python3
run to test:
% python --version
Python 3.14
## Running from an application
These provide a user interface to create, maintain, and run Python programs
PyCharm
Go to the PyCharm download page: jetbrains.com/pycharm/download
Select Download and run the installer
to run, launch PyCharm from the Start menu
VS Code (Windows)
Go to the VS Code download page: code.visualstudio.com/download 
Select Download and run the installer
to run, launch VS Code from the Start menu
Alternatively install Visual Studio Code from the Microsoft Store (latest version)
